# November Travel

부산 출발 22개 지역, 46개 추천 코스를 탐색하고 일정을 편집하는 다크·차콜 테마 여행 플래너입니다.

지도 재생, 장소 추가·삭제, 방문 순서와 날짜 변경, 체류시간 조절, 되돌리기·다시 실행, 일정 내보내기·가져오기를 지원합니다.

## GitHub에 게시

Node.js, Python 3, Git, GitHub CLI가 설치된 Mac 터미널에서 실행합니다.

```bash
bash deploy.sh
```

필요하면 GitHub 로그인을 안내합니다. 최초 실행은 `llouis0622/november-travel` 공개 저장소를 만들고 GitHub Pages를 설정합니다. 현재 연결된 저장소에서는 수정 사항을 검사·커밋·푸시하고 `gh-pages`를 갱신합니다. 연결 없이 같은 이름의 저장소가 이미 있으면 중단합니다. 게시 완료 뒤 실제 주소를 출력합니다.

## 직접 커밋해서 업데이트

이 파일들을 기존 저장소에 덮어쓴 뒤, 저장소 폴더에서 실행합니다. 새 압축 파일에는 `.git`이 없으므로 기존 저장소의 `.git`은 그대로 유지하세요.

```bash
python3 build.py
node test-editing.js
node test-responsive.js
python3 test-presentation.py
git add build.py ui.js ui.css deploy.sh test-responsive.js README.md dist/index.html
git commit -m "Improve responsive travel workspace"
git push origin main
git subtree push --prefix dist origin gh-pages
```

현재 게시 방식은 `gh-pages` 브랜치입니다. `main` 푸시 후 마지막 명령까지 실행해야 사이트에도 반영됩니다. 검사가 실패하면 다음 명령을 진행하지 마세요.

## 화면별 사용

- 900px 이하: 상단의 **지도 / 장소 / 일정**을 전환합니다. 지도와 장소 화면 아래에서는 날짜를 고르고, 일정 탭에서는 시간표와 방문 순서를 넓게 편집합니다.
- 900px 초과: 지도와 후보 목록을 나란히 보고 아래에서 일정을 편집합니다. 일정 확대 버튼으로 방문 목록을 크게 볼 수 있습니다.
- 모바일 방문 순서: 세로 카드에서 체류시간, 순서, 삭제, 날짜 이동을 조절합니다. 드래그가 불편하면 앞·뒤 버튼을 사용하세요.
- 일정에서 재생을 누르면 지도로 이동합니다. 장소·일정으로 전환하면 보이지 않는 지도의 재생은 일시정지됩니다.
- 편집창은 화면 안에서 스크롤하며 닫기 버튼을 유지합니다. 검색 중 한글 조합과 입력창의 포커스를 유지합니다.

## 개발

`ui.css`는 디자인, `ui.js`는 화면·편집·재생, `engine.js`는 일정 계산, `data.json`은 여행 데이터, `map-fragment.html`은 지도입니다.

```bash
python3 build.py
python3 -m http.server 8080 --directory dist
```

빌드 산출물은 `dist/index.html`입니다. 외부 API 키나 별도 서버 없이 실행됩니다. 여행지의 운영시간·요금·배차는 실시간 조회가 아닙니다.

일정은 브라우저의 로컬 저장소에 저장되며 기기 간 자동 동기화되지 않습니다. 기존 파일에서 수정한 일정은 ‘저장·가져오기’로 내보낸 뒤 새 사이트에서 가져오세요.

## 검증 범위

`deploy.sh`는 게시 전에 계산·편집·재생·상태·정적 마크업 검사를 실행합니다. 이 검사는 실제 브라우저의 화면 배치와 터치 검증을 대체하지 않습니다.

2026-10-23 반응형 수정본: 12개 화면 크기 조건(320×568부터 1920×1080, 740×360 가로 화면 포함)으로 46개 코스의 상태·편집·전환 검사를 실행했습니다. 크기별 미디어 조건을 설정한 DOM fixture 검사이며, 렌더링된 픽셀의 겹침·잘림이나 실제 기기 터치 검증이 아닙니다.

게시 후 기기별로 지도 이동·확대, 장소 검색과 추가, 금요일 날짜 탭, 방문 순서 변경, 삭제·되돌리기, JSON 저장·가져오기, 가로 회전, 키보드가 열린 상태의 검색·편집을 확인하세요. 실제 브라우저 제어 연결이 없어 이 수동 검증은 아직 수행되지 않았습니다.
